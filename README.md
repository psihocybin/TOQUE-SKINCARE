TOQUE Ritual

A PWA for onboarding clients after they purchase a TOQUE cosmetology device.
30 days of daily guided support, a personalized protocol, and upsell points
at day 30/60/90.

Brand guide, architectural principles, and structure are in docs/CLAUDE.md.

Stack

Next.js 14 (App Router) · TypeScript (strict) · Tailwind CSS · shadcn/ui ·
Framer Motion · Supabase · @ducanh2912/next-pwa · Vercel.

Getting started
bash
npm install
cp .env.example .env.local   # fill in Supabase keys, etc.
npm run dev                  # http://localhost:3000 → redirects to /splash
Scripts
bash
npm run dev      # dev server (PWA/service worker disabled)
npm run build    # production build
npm run start    # run the built app (PWA active)
npm run lint     # ESLint

node scripts/gen-icons.mjs   # regenerate placeholder PWA icons
PWA

The service worker is generated by @ducanh2912/next-pwa only in the production build.
To test "add to home screen" and offline support: npm run build && npm run start,
then check the Application tab in DevTools.

Icons in public/icon-*.png are temporary placeholders (olive + "T" monogram).
Replace with the final design assets.

Structure

See docs/CLAUDE.md. Briefly: route groups (auth), (onboarding), (main),
(modals) in app/; UI in components/; clients and content in lib/;
migrations and edge functions in supabase/.
