# Тестирование шагов процедур по устройствам

Шаги на `/ritual` теперь берутся динамически из протокола устройства
пользователя (`lib/content/protocols.ts`), а не хардкожены в
`lib/content/drip-campaign.ts`. Чтобы проверить это для устройства,
отличного от вашего собственного, временно смените `device` в профиле.

## Как временно сменить устройство для теста

1. Supabase Dashboard → Table Editor → таблица `profiles`
2. Найдите свою строку (по `id` или email)
3. Измените поле `device` на нужный slug в верхнем регистре с подчёркиванием
   (`NUO`, `ELARA`, `ANIMA`, `NOVA`, `AERIS`, `AURA`, `QUANTUM`, `VIBE`,
   `LYRA`, `SYLVA`) — это legacy-поле, `deviceEnumToSlug()` переводит его
   в slug (`nuo-pro` → `NUO_PRO` и т.д.)
4. Откройте `/ritual` — должны показаться шаги для нового устройства
5. Не забудьте вернуть исходное значение `device` после теста

## Ожидаемый результат по устройствам

**device = `nuo`, день с режимом Lifting** (например, день 5):
- Блок "Что нанести": "Сыворотка, гель или лёгкий крем на водной основе"
- Красный блок: "Только водная основа — масло блокирует ток"
- Шаги: 6 пунктов из реальной инструкции NUO
- Нет текста "масло-проводник"

**device = `nuo`, день с режимом Cleaning** (например, день 1):
- Блок "Что нанести": "Проводящий гель TOQUE CARE"
- Красный блок (ультразвук тоже не работает через масло)
- Шаги: 5 пунктов

**device = `anima`:**
- Блока "Что нанести" нет (medium пустой)
- Шаги: очистить кожу → надеть маску → выбрать программу → 10-20 минут → крем

**device = `nova` или `aeris`:**
- Блока "Что нанести" нет
- Шаги: снять линзы → надеть очки → выбрать режим → 15 минут

**device = `aura`:**
- Собственный экран `/ritual` (выбор режима из 4), не общий поток
- Режимы 1-4 и 6 — блок "Что нанести": масло/крем, зелёный блок
  "масло разрешено — нет тока"
- Режим 5 — блок "Что нанести": сыворотка, красный блок (есть микротоки)

**device = `lyra` / `sylva`:**
- Собственный экран `/ritual` с выбором Утренний/Вечерний/Экспресс,
  не общий поток drip-campaign

## Устройства без собственного протокола

`lumera`, `elara`, `pulsar` пока не имеют заполненных `modes` в
`protocols.ts` — для них блок "Что нанести" и список шагов на `/ritual`
будут пустыми, пока протокол не наполнен реальными данными.
