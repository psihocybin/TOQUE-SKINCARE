## КАК ТЕСТИРОВАТЬ

Открывай каждый URL в браузере, залогинен как test@toque.dev.
Отмечай ✅ или ❌ + что пошло не так.
Тестируй на телефоне (iPhone Safari / Android Chrome), не только на десктопе.

Перед началом — накати `docs/TEST_SETUP.sql` в Supabase SQL Editor
(требует применённых миграций 007–012). Разделы 1–10 предполагают
свежее состояние из этого файла (день программы = 7). Раздел 11
меняет `activated_at` дополнительно — см. его собственную инструкцию.

экран. Проверяй актуальную структуру:
